# USSReigns

**Игра в стиле Reigns про руководство СССР в период холодной войны (1946–1991).**

Принимай судьбоносные решения, балансируй между экономикой, элитами, народом, армией и мировым порядком. Не допусти ядерной войны и краха страны.

---

## Как запустить

1. Убедись, что установлен Python 3.8 или новее
2. Склонируй репозиторий:
   ```bash
   git clone https://github.com/deltaaqx/USSReigns.git
   cd USSReigns
3. Запуск игры
   ```bash
   python ussreigns.py
Никаких дополнительных библиотек не нужно — только стандартный Python и Tkinter (входит в стандартную поставку).\

Как играть
Ты — глава СССР. Тебе поступают карточки событий — исторических и нейтральных. У каждого события два варианта ответа. Твой выбор влияет на пять шкал:

Экономика (казна)

Поддержка элит (партийная верхушка)

Поддержка народа (население)

Мировой порядок (риск ядерной войны)

Армия (обороноспособность)

Если любая шкала достигает 0 или 100 — игра заканчивается.

Твоя задача — продержаться до конца 1991 года, балансируя между всеми шкалами.

Подсказки
Кнопка внизу экрана включает/выключает отображение эффектов на кнопках выбора. Играй вслепую или с подсказками — решать тебе.

Исторические и нейтральные события
[ИСТОРИЧЕСКОЕ] СОБЫТИЕ — реальное историческое событие, привязанное к конкретному году.

СОБЫТИЕ — нейтральное событие, реалистичное для советской эпохи, но без привязки к дате.

Добавление своих событий
Файлы historical_events.json и neutral_events.json можно редактировать вручную.
Формат события:
  ```json
  {
    "id": "уникальный_id",
    "year": 1946,
    "type": "historical",
    "title": "Название события",
    "description": "Описание (2-4 предложения)",
    "option_a": {
      "text": "Текст первой кнопки",
      "effects": {
        "economy": 0,
        "elites": 0,
        "people": 0,
        "world_order": 0,
        "army": 0
      },
      "flags_set": {},
      "flags_require": {}
    },
    "option_b": {
      "text": "Текст второй кнопки",
      "effects": {
        "economy": 0,
        "elites": 0,
        "people": 0,
        "world_order": 0,
        "army": 0
      },
      "flags_set": {},
      "flags_require": {}
    },
    "triggers_next_year": false
  }
```
triggers_next_year: true — поставить у последнего исторического события в году.

Концовки
В игре 11 концовок:

10 проигрышных (по одной на каждую шкалу при 0 и 100)

1 историческая — дожить до распада СССР в 1991 году

Также есть секретная концовка на 100 баллов мирового порядка. Попробуй найти.
